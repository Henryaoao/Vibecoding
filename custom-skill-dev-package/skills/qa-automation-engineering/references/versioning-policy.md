# Versioning Policy

Use semantic-style versioning.

- `MAJOR`: the QA operating model, routing model, or mandatory closeout contract changes materially
- `MINOR`: a new reusable QA capability, route pack, or governance layer is added
- `PATCH`: maintenance fixes, wording clarifications, or safer defaults

Before registering a release, confirm:

- the change is generalized
- the change is reviewable
- the release note explains whether the change affects shared QA rules, one route pack, or governance
