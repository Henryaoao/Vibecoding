# ProjectM UI Style 02 - Retro Futurism

This package is a portable snapshot of the ProjectM frontend styled with the retro-futurism reference:

- Neon cyan and pink glow system.
- CRT scanline overlay.
- Perspective grid background.
- Dark translucent panels.
- Pixel-inspired labels, controls, and module cards.

Run locally:

```bash
npm install
npm run dev -- --host 127.0.0.1
```

Build:

```bash
npm run build
```
