# ProjectM UI Style 01 - Stardew Glass Pixel

This archive contains the frontend source for the current ProjectM UI reference style.

Style name: `projectm-ui-style-01-stardew-glass-pixel`

Design mix:

- Stardew Valley inspired countryside pixel palette
- Frosted glass employee dashboard panels
- Pixel borders, hard shadows, pixel accents, and readable Chinese system typography
- CBCX logo in the left brand area

Included code:

- `src/`
- `public/cbcx-logo.svg`
- frontend config files needed to rebuild this Vite app

Excluded:

- `node_modules/`
- `dist/`

Run from this folder:

```bash
npm install
npm run dev
```
