# ProjectM 移动端 PRD

## 1. 文档定位

本文档是 ProjectM Mobile 的完整移动端需求源文档。后续没有新增或变更业务需求时，不应频繁修改本文档。

本文档可单独阅读并理解移动端 MVP 的完整需求。权限操作细则可参考 `docs/user-admin-permissions-guide.md`，但本文档不依赖其他 PRD 才能成立。

本文档只描述需求，不记录项目进度、架构变更历史或实施状态。

## 2. 产品概述

ProjectM Mobile 是公司内部信息门户的 iOS / Android 移动端应用。它服务普通员工和超级用户，让员工在手机上及时获取公司简报、公告、论坛热帖、新人资料、财经轻资讯、文档和培训内容，也让 `super_user` 能在移动端完成后台管理。

移动端不是 Web 端的精简版本。MVP 必须完整覆盖公司内部门户的核心业务能力，并针对手机场景增加推送通知、文件预览、安全 token 存储和移动端交互适配。

## 3. 产品目标

- 普通用户可在移动端查看首页和 7 个核心栏目。
- 普通用户可完成搜索、筛选、收藏、文档下载/预览、培训进度更新和新人任务完成。
- `super_user` 可在移动端完成完整 Admin Console 管理操作。
- 移动端通过推送通知提醒重要公告、简报、培训和新人任务。
- 移动端通过文件预览能力提升文档中心可用性。
- 移动端必须严格遵守 `user` / `super_user` 两角色权限边界。

## 4. 用户角色

系统只有两个应用角色。

| Role Code | 中文名称 | 移动端用途 |
| --- | --- | --- |
| `user` | 普通用户 | 使用 User Portal，查看已发布且有权限访问的内容、文档、课程和个人数据。 |
| `super_user` | 超级用户 | 拥有 `user` 的全部能力，并可使用完整移动端 Admin Console。 |

角色规则：

- `super_user` 继承 `user` 的全部前台能力。
- `user` 不能看到 Admin Console 入口。
- `user` 不能访问任何 Admin screen。
- `user` 调用 `/api/v1/admin/*` 必须返回 403。
- `super_user` 可访问所有 Admin Console 模块。
- 系统必须至少保留一个启用状态的 `super_user`。

## 6. MVP 范围

### 6.1 User Portal

移动端 User Portal 必须包含：

- 首页
- 今日公司简报
- 公司公告墙
- 员工论坛热帖
- 新人专区
- 财经轻资讯
- 文档中心
- 培训中心
- 个人中心

普通用户可执行：

- 浏览已发布内容。
- 搜索和筛选内容、文档、课程。
- 收藏内容和文档。
- 下载和预览有权限访问的文档。
- 更新自己的培训进度。
- 完成自己的新人任务。
- 查看自己的收藏、下载记录、培训进度和新人任务。

普通用户不可执行：

- 访问 Admin Console。
- 创建、编辑、发布、归档或删除内容。
- 上传、删除或修改文档。
- 创建、编辑或删除课程。
- 管理用户、角色、分类、标签或首页栏目配置。
- 查看审计日志。

### 6.2 Admin Console

移动端 Admin Console 必须包含：

- Dashboard
- 内容管理
- 文档管理
- 课程管理
- 新人任务管理
- 分类管理
- 标签管理
- 用户管理
- 角色权限
- 首页栏目配置
- 审计日志

`super_user` 可执行：

- 查看后台指标和最近操作。
- 管理今日公司简报、公司公告墙、员工论坛热帖、新人专区、财经轻资讯。
- 上传、编辑、发布、归档和软删除文档。
- 创建、编辑、发布、归档和软删除课程。
- 创建、编辑、排序、启用和禁用新人任务。
- 创建、编辑和禁用分类、标签。
- 创建用户、编辑用户、禁用用户、分配 `user` 或 `super_user`。
- 配置首页栏目启用状态、展示顺序和展示条数。
- 查看审计日志。

Admin 操作约束：

- 所有 Admin 写操作必须由后端校验 `super_user`。
- 删除内容、文档、课程和任务时必须软删除。
- 发布、归档、删除、禁用用户、修改角色必须二次确认。
- 关键写操作必须写入审计日志。
- 不允许禁用或移除系统最后一个启用状态的 `super_user`。

## 7. 用户门户模块需求

### 7.1 首页

首页目标是让员工打开 App 后立刻看到当天最重要的信息。

需求：

- 今日公司简报必须固定展示在首页顶部。
- 首页必须聚合展示 7 个核心栏目摘要。
- 首页栏目包括：今日公司简报、公司公告墙、员工论坛热帖、新人专区、财经轻资讯、文档中心、培训中心。
- 首页每个栏目最多展示 5 条摘要，实际数量遵循后端栏目配置。
- 首页必须支持下拉刷新。
- 首页必须有加载中、空状态、错误状态。
- 新人专区是否展示应遵循用户偏好和后端栏目配置。
- 首页栏目点击后进入对应列表或详情。

验收：

- `user` 登录后可进入首页。
- 今日公司简报位于首页顶部。
- 首页展示 7 个核心栏目入口或摘要。
- 禁用栏目不在首页展示。
- 用户无权限访问的内容不得出现在首页。

### 7.2 今日公司简报

今日公司简报用于汇总当天重点信息。

内容范围：

- 今日公告
- 今日活动
- 天气提醒
- 热门帖子
- 财经一句话
- 生日提醒

需求：

- 支持简报列表、简报详情、搜索和收藏。
- 摘要展示标题、日期、更新时间和 3-6 条重点信息。
- 详情展示完整正文、来源信息、发布时间、发布部门和阅读量。
- 无当日简报时展示最近一次已发布简报，并标记简报日期。
- `super_user` 可在 Admin Console 创建、编辑、发布、归档和软删除简报。

验收：

- 已发布简报对有权限用户可见。
- 草稿、归档、软删除简报不出现在普通用户列表。
- 无当日简报时不显示空白页。

### 7.3 公司公告墙

公司公告墙用于发布公司通知、节假日安排、调休提醒、办公区通知、福利通知和活动通知。

需求：

- 支持公告列表、详情、搜索、分类筛选、置顶标记和收藏。
- 公告详情展示标题、摘要、正文、附件、发布部门、有效期、发布时间和阅读量。
- 重要公告必须有明显标记。
- 过期公告默认不在首页展示，但可在公告列表或筛选结果中查询。
- `super_user` 可创建、编辑、保存草稿、发布、归档和软删除公告。

验收：

- 发布公告出现在公告墙和首页公告模块。
- 置顶公告在列表靠前展示。
- 草稿不对普通用户可见。
- 发布、归档、删除写入审计日志。

### 7.4 员工论坛热帖

员工论坛热帖用于展示公司论坛或内部讨论区的热门动态。

展示类型：

- 最近热门帖子
- 最新回复
- 每周讨论话题

需求：

- 支持热帖列表、详情或外部链接跳转。
- 展示标题、摘要、作者、发布时间、最新回复时间、浏览数、评论数、点赞数。
- 默认热度计算：`浏览数 + 评论数 * 3 + 点赞数 * 2`。
- 首页热帖模块至少展示 3 条内容。
- MVP 只展示热帖聚合，不实现完整发帖、评论、私信和举报。
- `super_user` 可人工维护热帖内容、排序和外部链接。

验收：

- 热帖列表按热度或配置排序。
- 外部链接不可用时展示错误提示。
- 普通用户不能维护热帖。

### 7.5 新人专区

新人专区帮助新员工完成入职初期信息获取和任务办理。

内容范围：

- 新人指南
- 办公区地图
- 常用系统说明
- 周边餐饮
- 常见问题
- 新人自我介绍墙
- 新人任务

需求：

- 支持新人内容列表、详情、搜索、收藏。
- 支持新人任务列表、任务详情和任务完成操作。
- 新人用户默认显示新人专区。
- 老员工可在个人偏好中隐藏首页新人专区模块。
- `user` 只能更新自己的新人任务状态。
- `super_user` 可维护新人内容和新人任务模板。

验收：

- 启用任务展示给普通用户。
- 禁用任务不展示给普通用户。
- 任务按 `sort_order` 升序展示。
- 用户只能完成自己的任务。

### 7.6 财经轻资讯

财经轻资讯体现公司金融属性，但必须严格控制合规边界。

内容范围：

- 财经早知道
- 指数概览
- 金融小知识
- 反诈提醒
- 财经日历

需求：

- 支持资讯列表、详情、标签筛选和收藏。
- 每条资讯展示标题、摘要、来源、发布日期、标签、正文和免责声明。
- 财经资讯由 `super_user` 人工发布。
- MVP 不自动抓取外部财经新闻。
- 每条财经资讯必须明确显示免责声明。

合规边界：

- 不提供股票推荐。
- 不提供买卖建议。
- 不提供个股预测。
- 不承诺收益。
- 不暗示确定性投资结论。
- 内容仅用于内部资讯阅读和安全教育。

验收：

- 财经详情页展示免责声明。
- 财经内容不得出现股票推荐、买卖建议、个股预测或收益承诺。
- 财经内容发布前由 `super_user` 人工确认。

### 7.7 文档中心

文档中心用于查找、预览和下载公司制度、模板、知识文档。

需求：

- 支持文档列表、详情、搜索、分类筛选、标签筛选、文件类型筛选。
- 支持 PDF、Word、Excel、PPT、图片文件。
- 单文件大小 MVP 限制为 50MB。
- 支持文档收藏。
- 支持文档下载。
- 支持移动端文件预览。
- 只展示用户有权限访问的已发布文档。
- 文档下载和预览行为必须按后端规则记录。
- 无权限文档不得泄露标题、摘要、文件名、下载地址或预览地址。

验收：

- 有权限用户可搜索、查看、预览和下载文档。
- 无权限用户无法看到文档信息。
- 文件过大或类型不支持时展示明确错误。
- 下载行为写入记录。

### 7.8 培训中心

培训中心用于员工学习课程并记录进度。

需求：

- 支持课程列表、课程详情、搜索、分类筛选。
- 课程可标记为必修或选修。
- 课程详情展示标题、摘要、说明、课程类型、资源链接、完成状态和进度。
- 用户可更新自己的学习进度。
- 用户可标记课程完成。
- 完成课程后，个人中心培训进度同步更新。
- MVP 不包含在线视频转码、直播培训、考试、证书和学习路径。

验收：

- 已发布课程对普通用户可见。
- 必修课程有明显标记。
- 用户只能更新自己的课程进度。
- 完成课程记录完成时间。

### 7.9 个人中心

个人中心聚合当前用户的个人数据。

需求：

- 展示用户基本资料、部门、角色、账号状态。
- 展示我的收藏。
- 展示文档下载记录。
- 展示培训进度。
- 展示新人任务。
- 支持管理通知偏好。
- 支持退出登录。
- `user` 不可修改角色、部门或账号状态。
- 退出登录后必须清理本地 token、用户缓存和设备状态。

验收：

- 用户只能查看自己的个人数据。
- 退出后再次进入受保护页面必须要求登录。
- 通知偏好保存后下次进入仍生效。

## 8. Admin Console 需求

移动端 Admin Console 必须使用适合手机屏幕的工作台体验，而不是直接复刻桌面表格。

### 8.1 Admin Dashboard

需求：

- 展示内容数量、待发布数量、阅读量、文档下载量、培训完成率。
- 展示最近操作记录。
- 展示 Admin 模块入口。
- 指标可接受最多 5 分钟缓存。

### 8.2 内容管理

管理内容类型：

- `daily_brief`
- `announcement`
- `forum_hot`
- `newcomer`
- `finance`

需求：

- 支持按内容类型、状态、关键词筛选。
- 支持新建、编辑、保存草稿、发布、归档、软删除。
- 状态至少包含 `draft`、`published`、`archived`。
- 发布、归档、删除必须二次确认。
- 所有写操作记录创建人、更新人、创建时间和更新时间。
- 所有关键写操作写入审计日志。

### 8.3 文档管理

需求：

- 支持上传或选择文件。
- 支持编辑标题、摘要、分类、标签、可见范围。
- 支持保存草稿、发布、归档、软删除。
- 文件大小超过 50MB 时拒绝上传。
- 不支持的文件类型必须提示错误。
- 发布文档可被有权限用户搜索、预览和下载。

### 8.4 课程管理

需求：

- 支持创建、编辑、发布、归档、软删除课程。
- 支持设置课程为必修或选修。
- 支持关联文档中心课件或外部课程链接。
- 发布课程出现在培训中心。
- Admin Dashboard 培训完成率随完成记录变化。

### 8.5 新人任务管理

需求：

- 支持创建、编辑、排序、启用、禁用新人任务模板。
- 任务包含标题、说明、排序和关联资源链接。
- 禁用任务不展示给普通用户。
- 任务排序按 `sort_order` 升序展示。

### 8.6 分类与标签管理

需求：

- 支持创建、编辑、禁用分类。
- 支持创建、编辑、禁用标签。
- 被内容引用的分类和标签不可硬删除，只能禁用。

### 8.7 用户与角色管理

需求：

- 支持创建用户、编辑用户、禁用用户。
- 支持分配 `user` 或 `super_user`。
- `disabled` 用户不能登录。
- 修改角色必须写入审计日志。
- 不允许禁用或移除最后一个启用状态的 `super_user`。

### 8.8 首页栏目配置

需求：

- 支持配置栏目启用状态。
- 支持配置栏目展示顺序。
- 支持配置每个栏目展示条数。
- 配置修改必须写入审计日志。

### 8.9 审计日志

需求：

- 支持搜索、筛选、查看审计日志详情。
- 审计日志至少覆盖登录、内容创建/更新/发布/归档/删除、文档上传/更新/删除/下载、课程创建/更新/删除、用户创建/更新/禁用/角色变更、首页栏目配置变更。
- 日志不得记录密码、JWT、数据库凭据、上传文件内容或敏感请求体。

## 9. 推送通知需求

移动端 MVP 支持推送通知。

通知类型：

- 重要公告发布。
- 今日公司简报发布。
- 必修培训提醒。
- 新人任务提醒。
- 文档或课程发布提醒。
- Admin 关键操作结果提醒，作为可选增强。

需求：

- 用户首次启用通知前必须请求系统权限。
- 用户拒绝通知权限时，应用其他功能仍可正常使用。
- 用户可在个人中心管理通知偏好。
- 登录成功后可注册设备 push token。
- 退出登录或账号禁用后，应解绑或停用设备 token。
- 推送内容不得包含密码、JWT、数据库信息、上传文件内容或敏感正文。
- 点击通知后进入对应详情页。
- 点击通知后如果用户无权限，展示 403 或资源不可用状态。

验收：

- iOS 和 Android 真机可注册 push token。
- 重要公告发布后，目标用户可收到推送。
- 关闭通知偏好后不再收到对应通知。
- `user` 不会收到 Admin 专属通知。
- 禁用用户不会继续收到推送。

## 10. 文件预览需求

移动端 MVP 支持文件预览。

支持范围：

- PDF：优先应用内预览或系统预览。
- 图片：优先应用内预览。
- Word、Excel、PPT：优先系统预览或外部应用打开。
- 不支持预览的文件必须保留下载入口和明确提示。

需求：

- 文件预览必须复用文档权限校验。
- 移动端通过短期有效 preview URL 打开文件。
- 无权限用户不能获取 preview URL、下载地址、文件名或 mime type。
- 大文件下载或预览必须展示进度、失败状态和重试入口。
- 离开预览页后不应泄露受保护文件到公共目录。

验收：

- PDF 可预览或通过系统预览打开。
- 图片可预览。
- Office 文件可通过系统预览或外部应用打开。
- 无权限用户不能预览或下载文档。
- 预览失败时展示明确错误和下载降级入口。

## 12. 数据要求

移动端依赖以下核心数据对象：

- 用户、角色、部门。
- 内容：简报、公告、热帖、新人内容、财经轻资讯。
- 文档：元数据、文件类型、可见范围、下载数、预览 URL。
- 课程：标题、摘要、说明、必修/选修、资源链接、进度。
- 新人任务：任务模板和用户任务状态。
- 收藏：资源类型、资源 ID、收藏时间。
- 下载记录：文档 ID、文件名快照、下载时间。
- 首页栏目配置：栏目 key、标题、启用状态、排序、展示条数。
- 审计日志：操作者、动作、资源类型、资源 ID、IP、User-Agent、时间。
- 移动设备：平台、push token、App 版本、启用状态。
- 通知偏好：用户通知类型开关。

数据规则：

- 普通用户列表只返回 `published` 状态内容。
- 普通用户文档列表只返回自己有权限访问的文档。
- 软删除数据默认不返回给普通用户。
- Admin Console 可按权限查看所有状态数据。
- 密码不得明文存储。
- 日志不得记录密码、token、数据库凭据、上传内容或敏感正文。

## 13. 非功能需求

### 13.1 性能

- 首页接口在内网环境 P95 响应时间目标为 500ms 内。
- 移动端首页首屏在标准办公网络下 P95 目标为 2 秒内。
- 文档搜索在 1 万条文档规模下 P95 目标为 800ms 内。
- 列表页必须支持分页或加载更多，避免一次性拉取大量数据。

### 13.2 安全

- 移动端 access token 必须使用安全存储。
- 所有生产环境 API 必须使用 HTTPS。
- 移动端必须处理 token 过期、账号禁用、401 和 403。
- `/api/v1/admin/*` 必须由后端强制校验 `super_user`。
- 文件上传和预览必须校验权限、文件大小、扩展名和 MIME 类型。
- CORS 和生产访问策略由后端控制，移动端不得绕过。

### 13.3 可维护性

- 移动端需求、架构和状态分离维护。
- 需求变更才修改 PRD。
- 技术设计调整历史记录在项目状态文件。
- 项目进度、问题和下一步记录在项目状态文件。

### 13.4 兼容性

- 移动端支持 iOS 和 Android。
- 推送和文件预览必须用真机验证。
- Expo Go 不作为推送验收依据。

## 14. 非 MVP 范围

移动端 MVP 不包含：

- 新增第三类应用角色。
- 用户浏览行为留存、行为追踪或分析画像。
- 完整论坛发帖、评论、私信和举报系统。
- 外部财经新闻自动抓取。
- 股票推荐、买卖建议、个股预测或收益承诺。
- 在线视频转码、直播培训、考试、证书和学习路径。
- Microsoft Teams / Entra ID SSO 登录。
- 离线优先编辑、离线冲突合并和后台同步。
- App Store / Google Play 正式上架流程。
- 移动端 Admin 批量操作。

## 15. 总体验收标准

### 15.1 普通用户验收

- `user` 可登录移动端。
- `user` 可查看首页和 7 个核心栏目。
- `user` 只能看到已发布且有权限访问的内容。
- `user` 可搜索、筛选、收藏和下载有权限的文档。
- `user` 可预览支持类型的文档。
- `user` 可查看课程、更新进度和完成课程。
- `user` 可查看并完成自己的新人任务。
- `user` 可管理通知偏好。
- `user` 看不到 Admin Console 入口。
- `user` 直接访问 Admin screen 时看到 403。
- `user` 调用 `/api/v1/admin/*` 时后端返回 403。

### 15.2 超级用户验收

- `super_user` 可登录移动端。
- `super_user` 可看到 Admin Console 入口。
- `super_user` 可访问所有移动端 Admin Console 模块。
- `super_user` 可创建、编辑、发布、归档、软删除内容。
- `super_user` 可上传、编辑、发布、归档、软删除文档。
- `super_user` 可创建、编辑、发布、归档、软删除课程。
- `super_user` 可管理新人任务、分类、标签和首页栏目。
- `super_user` 可创建用户、禁用用户、分配 `user` 或 `super_user`。
- `super_user` 关键写操作必须写入审计日志。

### 15.3 推送验收

- iOS 真机可请求通知权限并注册 push token。
- Android 真机可请求通知权限并注册 push token。
- 重要公告或简报发布后，目标用户可收到通知。
- 用户关闭通知偏好后不再收到对应类型通知。
- 退出登录或账号禁用后设备 token 停用。

### 15.4 文件预览验收

- PDF 可预览或通过系统预览打开。
- 图片可预览。
- Office 文件可通过系统预览或外部应用打开。
- 无权限用户不能预览或下载文档。
- 预览失败时展示明确错误和下载降级入口。
