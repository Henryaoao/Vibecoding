# ProjectM Mobile 搁置文档区

## 状态

本目录保存已搁置但不得删除的移动端历史文档和参考材料。

## 分类

- 根目录历史文档：旧移动端 PRD、旧 agent 工作流或能力审计。
- `features/`：按功能分类搁置的移动端实现文件、测试和恢复说明。

## 使用规则

- 本目录内文件不是当前 ProjectM Mobile 事实来源。
- 后续 PRD、实现、验收、测试和 agent 工作流不得引用或继承本目录内文件。
- 如需恢复本目录内任一文件的内容，必须先向用户确认，再迁移到当前事实来源位置。
- 没有用户明确确认，不得修改当前需求文档来追随本目录内的历史内容。
