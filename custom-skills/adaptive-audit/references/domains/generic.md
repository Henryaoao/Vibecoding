# Generic Standards Pack

Use this pack when the artifact does not fit a mature domain pack yet.

Apply this pack in addition to `references/common-checklist.md`.

## 1. Clarity

Check:

- purpose
- scope
- audience
- expected outcome

## 2. Logic

Check:

- main claims or actions
- success path
- failure path
- important edge conditions

## 3. Evidence

Check:

- what is proven
- what is inferred
- what remains unknown

## 4. Observability

Check:

- whether someone else could verify the artifact
- whether key outcomes are observable
- whether follow-up actions are clear
