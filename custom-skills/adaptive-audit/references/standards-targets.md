## Cross-Domain Rule

If a principle generalizes across multiple domains, prefer updating:

- `references/common-checklist.md`
- `references/universal-audit-core.md`
- `references/domain-router.md`
- `references/evidence-discipline.md`

Use `references/common-checklist.md` when the principle should become a mandatory shared check for all audits.

Use `references/universal-audit-core.md` when the principle changes the general audit reasoning model rather than a checklist item.

Do not duplicate the same principle into every domain file unless the domain expression truly differs.
