# Release Log

## Current Version

- Version: 2.0.0
- Date: 2026-05-26
- Summary: Integrated adaptive-audit into the shared custom-skills library with runtime inbox overlay and maintainer-only canonical evolution writes.

## Releases

### 2.0.0 - 2026-05-26

- Integrated `adaptive-audit` into the shared `custom-skills` library as a portable cross-project skill.
- Added runtime inbox overlay loading so collaborator-local unmerged audit learning can guide future runs without mutating installed skill files.
- Changed `scripts/run_post_audit_evolution.py` so ordinary collaborator closeouts append to sibling `evolution-inbox/` records only.
- Added `--allow-canonical-write` for maintainer merge/release workflows that deliberately write canonical `evolution-memory.md` and `evolution-log.jsonl`.
- Updated install handoff, post-audit evolution, and UI metadata to match the shared inbox-only collaborator model.
