# Generalization Ladder

Never evolve directly from an incident to a permanent rule.

## 1. Symptom

The concrete thing that happened.

## 2. Failure Mode

The reusable class of mistake or gap behind the symptom.

## 3. Principle

The generalized thinking habit that would have caught the failure mode.

## 4. Rule

The reusable instruction that can safely enter a skill, checklist, or governance layer.

## 5. Promotion Test

Remove the product name, route, team, and exact wording.  
If the lesson still makes sense, it is closer to a principle.  
If not, it is still too case-specific.
