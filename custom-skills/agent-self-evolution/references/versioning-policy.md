# Versioning Policy

Use semantic-style versioning.

- `MAJOR`: the meta-skill's operating philosophy, mandatory gate, or governance changes materially
- `MINOR`: a new reusable capability, integration pattern, dimension, or generalized principle is added
- `PATCH`: maintenance fixes, wording clarifications, tooling fixes, or safer defaults

Before registering a release, confirm:

- the change is generalized
- the change is reviewable
- the change is described in release notes
