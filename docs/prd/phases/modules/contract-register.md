# ProjectM 模块合同登记表

## 1. 目的

本文登记七个 MVP 模块在数据库、后端、Web 前端和 App 前端之间的关键合同。它不是字段大全，而是避免端侧或后端在执行中静默重写事实的协调表。

## 2. 通用合同

- 角色只能是 `user` 与 `super_user`。
- 员工端接口只返回当前用户有权限访问的内容。
- 管理接口位于 `/api/v1/admin/*` 或 API 基础阶段确认的等价命名空间，并要求 `super_user`。
- Web Admin Console 承担所有管理写入。
- App 不包含移动端管理写入。
- 不得实现浏览历史、`recent_views` 或页面访问轨迹。
- 财经轻资讯不得包含股票推荐、买卖建议、个股预测或收益承诺。

## 4. 合同变更规则

如果任何阶段 PRD 或实现任务需要新增、删除或改变以下内容，必须更新本文件并说明原因：

- 后端接口路径或权限。
- 内容生命周期状态。
- 端侧需要的新字段或状态。
- 数据库必须保存的新业务事实。
- 影响 Web 与 App 同时消费的错误、分页、筛选或排序规则。

## 5. 验收要求

- 28 份模块阶段 PRD 都能指向本登记表。
- Web 与 App 不在端侧 PRD 中自行定义后端权限事实。
- App 合同不包含移动端管理写入。
- 财经轻资讯合同保持非投资建议边界。
