# P01 Stage Done Criteria

P01 完成后，下一阶段可以从统一整合分支继续。

## 阶段完成标准

- D 平台运行基线已合并。
- B Web shell 基线已合并。
- A 信息发布基础边界已合并。
- C App / 社区 / 新人 / 财经基础边界已合并。
- 默认端口保持：Web `3000`、Backend `8080`、PostgreSQL `5432`、pgAdmin `5050`。
- 角色仍只有 `user` 和 `super_user`。
- `/api/v1/admin/*` 仍以后端 `super_user` 授权为事实来源。
- App 未引入移动端管理写入。
- 未实现浏览历史、`recent_views` 或访问轨迹。
- 财经轻资讯边界仍为非投资建议。
- 未提交真实 `.env` 或真实凭据。

## 最低验证证据

每个席位必须回报：

- 分支名。
- commit SHA。
- 创建自哪个基线分支和 SHA。
- 修改文件摘要。
- 验证命令和结果。
- 未完成项或阻塞项。

整合负责人必须回报：

- 实际合并顺序。
- 冲突文件和解决摘要。
- 验证命令和结果。
- 目标整合分支 commit SHA。
- 是否已 push。
- 是否可以进入 P02。

## 分发说明

每个人直接运行自己目录下的 `omx-team-command.txt`。这些文件已经包含 `omx team ...` 终端命令，不需要在前面额外加 `$team`。

## 返工条件

出现以下任一情况，不进入下一阶段：

- 未 push 的前置基线被下游使用。
- 引入第三种角色。
- 前端隐藏权限被当成权限事实来源。
- App 引入管理写入。
- Finance 内容或字段暗示投资建议、买卖建议、个股预测或收益承诺。
- 提交中包含真实密钥。
- P01 分支实现了 P02+ 的业务范围。
