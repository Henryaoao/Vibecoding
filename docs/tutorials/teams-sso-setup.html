ProjectM Teams SSO 配置教程

适用范围：ProjectM 本地开发环境，使用 Microsoft Teams / Microsoft Entra ID 的 OAuth 2.0 授权码登录。生成日期：2026-05-28。

目标：拿到 TEAMS_CLIENT_ID、TEAMS_CLIENT_SECRET、TEAMS_TENANT_ID，并在 Microsoft Entra 中配置 ProjectM 本地回调地址。

1. 当前 ProjectM 需要的值

ProjectM 的 .env 中需要补齐这几个 Teams SSO 配置：

TEAMS_CLIENT_ID=
TEAMS_CLIENT_SECRET=
TEAMS_TENANT_ID=
TEAMS_REDIRECT_URI=http://localhost:8080/api/v1/auth/teams/callback

下面这些可以先留空，ProjectM 后端会按 TEAMS_TENANT_ID 自动使用默认值：

TEAMS_AUTH_URL=
TEAMS_TOKEN_URL=
TEAMS_USERINFO_URL=
TEAMS_SCOPES=

默认端点与 scope 为：

https://login.microsoftonline.com/{tenant}/oauth2/v2.0/authorize
https://login.microsoftonline.com/{tenant}/oauth2/v2.0/token
https://graph.microsoft.com/oidc/userinfo
openid profile email

2. 创建 Microsoft Entra App Registration

  1. 打开 Microsoft Entra admin center。
  2. 进入 Applications → App registrations。
  3. 点击 New registration。
  4. 名称建议填写：ProjectM Local。
  5. Supported account types 建议先选择当前组织目录。
  6. 点击 Register。

创建完成后，在 app 概览页复制：

Application (client) ID  -> TEAMS_CLIENT_ID
Directory (tenant) ID    -> TEAMS_TENANT_ID

3. 配置 Redirect URI

  1. 在刚创建的 App Registration 中进入 Authentication。
  2. 点击 Add a platform。
  3. 选择 Web。
  4. 填写 ProjectM 本地回调地址：
http://localhost:8080/api/v1/auth/teams/callback

保存后，Microsoft identity platform 才会允许 ProjectM 使用这个地址接收授权码。

4. 创建 Client Secret

  1. 进入 Certificates & secrets。
  2. 点击 New client secret。
  3. 描述可写：ProjectM local dev。
  4. 选择合适的过期时间，例如 6 months。
  5. 创建后立刻复制 Value。
注意：这里要复制的是 Value，不是 Secret ID。离开页面后 Value 通常不会再次完整显示。

把复制到的 Value 填到：

TEAMS_CLIENT_SECRET=你的-client-secret-value

5. 填写 ProjectM 本地 .env

最终本地 .env 中 Teams 部分应类似：

TEAMS_CLIENT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
TEAMS_CLIENT_SECRET=你的-client-secret-value
TEAMS_TENANT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
TEAMS_REDIRECT_URI=http://localhost:8080/api/v1/auth/teams/callback

TEAMS_AUTH_URL=
TEAMS_TOKEN_URL=
TEAMS_USERINFO_URL=
TEAMS_SCOPES=

如果你暂时想允许多租户或不确定 tenant，可先使用：

TEAMS_TENANT_ID=common

6. 重启 ProjectM 并验证

保存 .env 后，在仓库根目录运行：

docker compose up --build -d backend frontend

然后打开：

http://localhost:3000/

点击 使用 Teams 登录。成功时会进入 Microsoft 登录页，登录后回到 ProjectM。

7. 快速故障排查

  • 如果看到 TEAMS_AUTH_UNAVAILABLE：通常是 TEAMS_CLIENT_ID 或 TEAMS_CLIENT_SECRET 为空。
  • 如果 Microsoft 提示 redirect URI mismatch：确认 Entra 中的 URI 和 TEAMS_REDIRECT_URI 完全一致。
  • 如果 token exchange 失败：确认 client secret 复制的是 Value，且没有过期。
  • 如果登录后没有用户：确认 scope 至少包含 openid profile email。
  • 如果本地服务打不开：确认 Docker 中 projectm_backend 和 projectm_frontend 都在运行。

8. Web OAuth 与 Teams Tab SSO 的区别

ProjectM 当前实现的是浏览器中的 Microsoft Entra OAuth/OIDC 登录，也就是通过网页跳转到 Microsoft 登录页，再回调到 ProjectM。

如果未来要把 ProjectM 嵌入 Microsoft Teams 客户端作为 Tab，并使用 Teams 客户端内的无感 SSO，还需要额外配置 Teams app manifest、Expose an API、Application ID URI、scope，以及 Teams client pre-authorization。这属于下一阶段能力，不是当前本地网页登录必须项。
