# ProjectM Agent Guide Index

This folder keeps the detailed agent operating guidance for ProjectM. `AGENTS.md` is the short entry point; these files hold the longer reference material.

Read in this order when relevant:

1. `omx-workflows.md` for OMX active agents, workflow skills, and how they map to ProjectM work.
2. `project-roles.md` for ProjectM role responsibilities, expert switch labels, and role-specific guardrails.
3. `capability-governance.md` for AI / Agent modification permissions, document-structure protection, self-verification gates, and handoff rules.
4. `skills.md` for installed skills, portable skill fallback, and non-native skill handling.
5. `verification.md` for development commands, documentation rules, implementation rules, and completion checks.
