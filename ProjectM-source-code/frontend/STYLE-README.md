# ProjectM UI Style 03 - Pink Pixel Art

This package is a portable snapshot of the ProjectM frontend styled with the pink pixel-art reference:

- Soft pink wall and pastel room background.
- Checker floor texture.
- Cream task-card panels.
- Square pixel borders and chunky shadows.
- Cozy RPG-like navigation and buttons.

Run locally:

```bash
npm install
npm run dev -- --host 127.0.0.1
```

Build:

```bash
npm run build
```
